# FK_DISPIMG
转换WPS创建的XLSX文件因为=@_xlfn.DISPIMG这个鬼玩意导致office excel和其他excel类软件无法显示图片的问题
简单说，WPS这个毒瘤玩意插入图片是用它自己的dispimg函数放到单元格里的，保存后的xlsx文件里虽然包含了图片文件，但是普通的excel、onlyoffice、libraoffice等等是打开后无法正常显示图片的。
然而作为文件的接受方，正常来说你要么自己安装wps，要么要求发送方给你转成嵌入图片
mother fucker，EXCEL是电子表格数据处理，不是tm的表单报表软件。但是你跟那些老逼登和不思进取的老姐们老哥们讲这个屁用没有。
所以用此py脚本可以解决。
把脚本最后的文件地址替换一下。
转换出来的excel表格...我还要教吗？你要图片大一点，先批量把单元格行选中，拉大点，然后定位选对象，再调整图片大小就行。
